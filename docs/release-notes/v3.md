## New modules
- `niche.py` and `youtube_api.py`:
  - evidence ledger and transparent weighted scoring
  - confidence lowered for niche-level evidence
  - revenue evidence recorded by category only (no invented RPM)
  - 30-episode roadmap and 90-day calendar
  - optional Data API collection (`YT_API_KEY`)
- `audience.py`: 50+ presentation profile and audit. The renderer now auto-corrects text to WCAG AA contrast.
- `history.py`: source tiers, claim classes (established / contested / allegation / reconstruction) and a fact-check report.
- `story.py`: 12–45 minute documentary structure, budgets and checks.
- `map` element (GeoJSON) and `archival` engine for labelled recreations.
- `dubbing.py`:
  - one master video and per-language tracks fitted to the master slots (no overlap; tempo up to 1.12× at quality level)
  - exact-length WAV/AAC, localized SRT and metadata
  - QA report and a Studio upload package
- `voice.py`: `auto` / `edge-tts` / `elevenlabs` / `sapi`, caching, character usage, quota guard, and the agent-delegated ElevenLabs MCP jobs/ingest/verify flow.
- `analytics.py`: Studio CSV and API ingestion, plus progress toward the US 55+ target (no 50+ bucket exists in the API).
- `seo.py`: publishing checklist, covering the inauthentic-content policy, advertiser rules and AI disclosure.

## Verified platform facts (official docs, 2026-10-14)
- The Data API has no endpoint for uploading audio tracks.
- Multi-language audio needs Advanced features.
- Age groups are age55-64 and age65-.
- Impressions and CTR are not available in the Analytics API.
- RPM and CPM are different metrics.

See `references/youtube-api-notes.md`.

## Known limitations
- ElevenLabs is **not connected**. The MCP server is absent from this session, so the adapter stays disabled until `voice verify-elevenlabs` succeeds.
- Niche evidence was gathered from public pages. YouTube pages were parsed from public HTML, which is a ToS grey area; prefer the Data API. Google Trends was unavailable (HTTP 429).
- The Spanish translation is a partial sample by Claude and needs native review before publication.
- The default English voice is Microsoft Edge neural TTS. Check Microsoft's terms for commercial use.
