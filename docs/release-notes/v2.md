## New features
- **`html_seek` engine:**
  - Network is restricted to localhost.
  - Missing upstream fonts get a logged font fallback.
  - The adapter supports four page contracts.
- **Unified style registry and verification:**
  - `studio.py styles --verify` renders a sample per style and rejects blank or static output.
  - 18/19 styles are operational on the dev machine.
- **Art direction, shot planning and continuity:**
  - `studio.py direction` and `art_style` per scene.
  - Shot, camera and transition are auto-filled from scene purpose.
  - The style proposal is 1 recommended + 2 alternatives, drawn only from verified styles.
- **Router:** aspect-aware (landscape-only engines are skipped for 9:16) and uses an information-density signal.
- **Fixes:** Shorts now apply `art_style`, and segment params are merged; kinetic phrases no longer overlap.
- **Reporting:** a production report and QA richness metric.

## Architecture changes
- The engine registry gains `html_seek`.
- Transitions are extended in `engines/base.py`.
- New modules: `styles.py` and `direction.py`.
- Spec defaults no longer pre-fill camera and transition, so the planner can fill them.

## Compatibility
- V1 projects build unchanged.
- The schema stays v2.
- Cache keys include the engine code hash, so V2 changes re-render affected scenes once.

## Known limitations
- mg.liquid (WebGL) renders black in headless Chromium here.
- Most lemo and mg demos need font binaries that upstream does not distribute; with the fallback font, typography is degraded.
- Upstream demo films show their own content. Using these styles for your own story requires authoring pages in their style.
